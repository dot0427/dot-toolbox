LDRS

一行標籤就能放上可愛的 Loading 動畫，純 HTML 也能用。

1一句話認識它

LDRS 是 uiball 出的 Loading 動畫集合，做成 Web Components，所以不管是純 HTML 還是 React 都能用，一行自訂標籤就有一個精緻的讀取動畫。

2什麼時候用得到

  • 表單送出後等待回應時的 Loading
  • 抽獎網頁按下按鈕到結果出現之間的轉場
  • 圖片、資料還沒載入完成時的佔位

3怎麼開始

在 HTML 裡用 module 引入想要的 loader，再放對應標籤：

<script type="module" src="https://cdn.jsdelivr.net/npm/ldrs/dist/auto/ring.js"></script>

<l-ring size="40" color="coral"></l-ring>
