Lenis

讓整個網頁捲動變得滑順有質感，很多得獎網站都在用。

1一句話認識它

Lenis 是 darkroom.engineering 做的平滑捲動函式庫。裝上去之後滑鼠滾輪捲動會變得順順的、有慣性，網站質感瞬間提升。

它很輕量，而且可以跟 GSAP ScrollTrigger 一起用。

2什麼時候用得到

  • 作品集網站，想要「高級感」的捲動體驗
  • 長篇的活動介紹頁、故事型網頁
  • 搭配 GSAP 做捲動視差效果

3怎麼開始

CDN 引入後建立一個實例：

<script src="https://unpkg.com/lenis@1/dist/lenis.min.js"></script>
<script>
  const lenis = new Lenis({ autoRaf: true });
</script>

官方也建議引入它的建議 CSS，詳細設定（速度、方向、跟 GSAP 整合）請看 GitHub README。
