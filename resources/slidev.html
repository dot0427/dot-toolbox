Slidev

用 Markdown 寫簡報，程式碼高亮和動畫都內建，適合技術報告。

1一句話認識它

Slidev 讓你用 Markdown 寫簡報，一個 --- 就是換頁。內建程式碼高亮、動畫、演講者模式，還能匯出 PDF。很適合工程類的報告。

2什麼時候用得到

  • 期中、期末報告需要秀很多程式碼的時候
  • 想用 Git 管理簡報版本
  • 讓 AI 直接幫忙生成 Markdown 簡報再微調

3怎麼開始

需要先裝 Node.js，接著：

npm init slidev@latest

建立後編輯 slides.md，用 --- 分隔每一頁。
