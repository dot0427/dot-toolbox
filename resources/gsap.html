GSAP

最老牌也最強的 JS 動畫引擎，時間軸、捲動觸發、拆字動畫都能做。

1一句話認識它

GSAP（GreenSock Animation Platform）是寫網頁動畫的老大哥。位移、縮放、顏色、SVG 路徑都能動，還能用時間軸把一連串動畫排好順序。

現在連 ScrollTrigger、SplitText 這些以前要付費的外掛也都免費了，做「捲到哪、動到哪」的效果特別好用。

2什麼時候用得到

  • 活動網頁的開場動畫，標題一個字一個字跳出來
  • 作品集首頁捲動時，專案卡片依序浮現（ScrollTrigger）
  • 應援網頁的 SVG 圖案描邊動畫
  • 需要精準控制先後順序的多段動畫（Timeline）

3怎麼開始

最快的方式是用 CDN，貼在 </body> 前面：

<script src="https://cdn.jsdelivr.net/npm/gsap@3/dist/gsap.min.js"></script>
<script>
  gsap.to(".box", { x: 200, rotation: 360, duration: 1.2 });
</script>
