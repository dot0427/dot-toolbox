Remotion Skills

讓 AI 學會用 Remotion 寫程式做影片，動態字卡、片頭都能生。

1一句話認識它

Remotion 讓你用 React 寫程式來「做影片」：每一幀都是一個畫面元件，最後輸出成 MP4。

remotion-dev/skills 則是給 AI Agent 的技能包，讓 Claude 之類的 AI 懂得 Remotion 的寫法，幫你直接生出影片程式碼。

2什麼時候用得到

  • 活動宣傳的動態字卡、倒數影片
  • 應援影片的片頭、歌詞字幕動畫
  • 把作品集專案做成一支短 Demo 影片

3怎麼開始

建立一個 Remotion 專案：

npx create-video@latest

幫 AI Agent 加上 Remotion 技能：

npx skills add remotion-dev/skills
