React Bits

一大包可以直接複製的動畫元件與背景特效，挑一個貼上就好看。

1一句話認識它

React Bits 是一個開源的動畫元件合集：文字特效、會動的背景、滑鼠互動效果、卡片⋯⋯每個元件都可以直接複製程式碼來用。

2什麼時候用得到

  • 想找網頁背景特效的靈感（就算不用 React 也可以先看效果）
  • 之後學 React 時，拿來練習把元件放進專案
  • 做作品集時找一個吸睛的 Hero 文字效果

3怎麼開始

到官網挑一個元件 → 選擇 JS/TS 與 CSS/Tailwind 版本 → 照頁面上的指示複製程式碼或用 CLI 安裝到 React 專案裡。

需要先有一個 React 專案，安裝方式請參考官網每個元件的說明。

4豆特筆記

還沒實際用過，先收藏。我目前還沒學過 React，這個先當「效果靈感圖鑑」看，之後學 React 再回來用。
